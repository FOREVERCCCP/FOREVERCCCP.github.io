「ポーランドボールクリッカー」では、第三者が提供するソフトウェア、ライブラリおよびサービスを利用しています。

各ソフトウェア等の著作権は、それぞれの著作権者に帰属します。

## Android / AndroidX

本アプリでは、AndroidおよびAndroidXの各種ライブラリを利用しています。

Android Open Source ProjectおよびAndroidXの多くのコンポーネントは、Apache License 2.0の条件に基づいて提供されています。

Apache License 2.0：  
https://www.apache.org/licenses/LICENSE-2.0

Android Developers：  
https://developer.android.com/

## Jetpack Compose

本アプリのユーザーインターフェースには、Jetpack Composeを利用しています。

Jetpack Composeを含むAndroidXライブラリは、それぞれのライセンス条件に基づいて提供されています。

https://developer.android.com/jetpack/compose

## Kotlin

本アプリはKotlinを使用して開発されています。

Kotlinおよび関連ライブラリは、それぞれのライセンス条件に基づいて提供されています。

Kotlin：  
https://kotlinlang.org/

Kotlin GitHub Repository：  
https://github.com/JetBrains/kotlin

## Kotlin Coroutines

非同期処理等のため、Kotlin Coroutinesを利用しています。

Kotlin CoroutinesはApache License 2.0の条件に基づいて提供されています。

https://github.com/Kotlin/kotlinx.coroutines

## Google Mobile Ads SDK

本アプリでは広告配信のため、Google Mobile Ads SDKを利用しています。

https://developers.google.com/admob/android/quick-start

Googleが提供するサービスおよびSDKには、Googleが定める利用規約その他の条件が適用されます。

## Google User Messaging Platform

広告に関する同意およびプライバシー設定の管理のため、Google User Messaging Platform（UMP）を利用しています。

https://developers.google.com/admob/android/privacy

## Firebase

ユーザーが任意で許可した場合の利用状況分析等のため、FirebaseおよびGoogle Analytics for Firebaseを利用する場合があります。

https://firebase.google.com/

Firebaseで提供される各ライブラリには、それぞれのライセンス条件およびGoogleの利用規約が適用されます。

## Google Play Games Services

ランキング等のゲーム機能のため、Google Play Games Servicesを利用する場合があります。

https://developer.android.com/games/pgs

Google Play Games Servicesには、Googleが定める利用規約その他の条件が適用されます。

## その他の素材

本アプリで使用する画像、音声、フォントその他の素材については、開発者が作成したもの、または利用条件に基づき使用が認められたものを使用しています。

第三者による個別の著作権表示またはライセンス表示が必要な素材については、その条件に従います。
